## О проекте

**RJ CMS** — современная самостоятельно размещаемая система управления контентом на базе **Laravel 12**. Вы устанавливаете её на собственный хостинг, полностью сохраняете владение данными и расширяете возможности через изолированную систему плагинов и тем. В комплект входят визуальный конструктор страниц (RJBuilder) с более чем 80 виджетами, встроенный **генератор маркетинговых постов**, двойной ИИ-движок, **55 языков** с отдельными URL для каждого языка, **двухуровневая система кеширования** (Response Cache + LiteSpeed LSCache) и браузерный установщик, работающий на любом виртуальном хостинге или VPS.

**RJ Nexus** — организация, стоящая за проектом. Она поддерживает ядро CMS и всю экосистему вокруг него.

Официальный сайт: **[rjnexus.org](https://rjnexus.org)**

## Установка

RJ CMS устанавливается на любой виртуальный хостинг или VPS без правки единой строки кода.

1. **Загрузка.** Скачайте последний ZIP-релиз и распакуйте его на веб-сервере (например, в `public_html`).
2. **Запуск установщика.** Откройте в браузере `https://yourdomain.com/install.php`.
3. **Следуйте шагам.** Выберите язык, проверьте требования к серверу, введите данные базы данных и создайте учётную запись администратора.
4. **Демо-данные.** Установщик импортирует страницы по умолчанию, меню и шаблоны конструктора, поэтому ваш сайт не начнёт работу пустым.
5. **Защита сайта.** Удалите `install.php` и папку `installer/`, когда мастер установки предложит это сделать.

## Кеширование

RJ CMS поставляется со встроенной двухуровневой системой кеширования страниц, поэтому ваш сайт остаётся быстрым при реальной нагрузке даже на скромном виртуальном хостинге.

<table>
  <tr>
    <td width="50%" valign="top">
      <img src="https://raw.githubusercontent.com/rj-nexus/rj-nexus.github.io/main/assets/svg/performance.svg" width="44" height="44" alt=""/><br/>
      <b>Response Cache</b><br/>
      Работает на <a href="https://github.com/spatie/laravel-responsecache"><code>laravel-responsecache</code></a>. Полные ответы приложения сохраняются и отдаются напрямую при повторных запросах, что позволяет пропустить большую часть работы фреймворка. Работает на любом хостинге, специальный сервер не требуется.
    </td>
    <td width="50%" valign="top">
      <img src="https://raw.githubusercontent.com/rj-nexus/rj-nexus.github.io/main/assets/svg/modular.svg" width="44" height="44" alt=""/><br/>
      <b>LiteSpeed Cache (LSCache)</b><br/>
      Работает на <a href="https://github.com/litespeedtech/lscache-laravel"><code>litespeed/lscache-laravel</code></a>. На хостингах LiteSpeed и OpenLiteSpeed страницы кешируются на уровне веб-сервера и отдаются ещё до запуска PHP.
    </td>
  </tr>
</table>

| | Response Cache | LiteSpeed LSCache |
|---|---|---|
| Пакет | `laravel-responsecache` | `litespeed/lscache-laravel` |
| Уровень кеша | Приложение (Laravel) | Веб-сервер (LiteSpeed) |
| Требование к хостингу | Любой PHP-хостинг | LiteSpeed / OpenLiteSpeed |
| Лучше всего подходит для | Универсального базового ускорения | Максимальной скорости на хостингах LiteSpeed |

Поведением кеша можно управлять в разделе **Админ-панель &rarr; Настройки &rarr; Кеш**.

## Участие в разработке
