## 📖 About

Spotlight is a highly customizable, dark-first theme designed for **product showcases**, **SaaS platforms**, and **content creators**. It integrates deeply with RJBuilder, giving you full control over your layout, colors, and content directly from the admin panel — without writing a single line of code.

## ✨ Features

| Feature | Description |
| --- | --- |
| **RJBuilder Integration** | 10+ custom-built widgets tailored specifically for this dark theme. |
| **Cinematic Hero** | Full-screen video backgrounds with ping-pong playback, color grading, and HUD overlays. |
| **Glassmorphism UI** | Beautiful frosted-glass effects, interactive tabs, and glowing borders. |
| **Dynamic Customizer** | Live CSS variables for colors, typography, and layout. Changes reflect instantly. |
| **Interactive Elements** | Animated pricing tables, infinite marquee testimonials, and accordion FAQs. |
| **Advanced Forms** | A newsletter signup with a "Black Hole" animation that swallows the form on success. |
| **Multilingual** | Built-in language switcher with automatic RTL support and localized routing. |
| **Custom Page Templates** | Dedicated templates for Contact, Landing, and Full-Width pages. |
| **Performance First** | Lightweight, using pure CSS animations and minimal JS. |

## 🚀 Installation

1. Clone or download this repository into the RJ CMS themes directory:

   ```bash
   cd rj-content/themes
   git clone https://github.com/rj-nexus/spotlight.git
   ```

2. Log in to the RJ CMS admin panel.
3. Go to **Appearance → Themes**.
4. Find **Spotlight** and click **Activate**.
5. Open the **Customizer** to set your global colors, fonts, and layout.

## 🧱 Getting Started with RJBuilder

1. Go to **RJBuilder** in the admin panel.
2. Create a new **Page** or **Template** (Header/Footer).
3. Find the **Spotlight** category in the block list.
4. Drag and drop the widgets to build your page.

### Available Widgets

- **Structure:** Glass Header, Structural Footer, Text Divider.
- **Heroes:** Cinematic Hero (Video/Image).
- **Content:** Spotlight Showcase, Animated Tabs, Features Grid, Step-by-Step Guide.
- **Social Proof:** Marquee Logos, Testimonials (Globe).
- **Conversion:** Premium Pricing, FAQ Accordion, Newsletter (Black Hole).

> [!TIP]
> Use the Customizer for global styles (colors, fonts, layout) and individual widget settings for per-section content. All widgets respect the global dark theme and customizer colors.
