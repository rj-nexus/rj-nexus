## 📖 About

Spotlight is a highly customizable, dark-first theme designed for **product showcases**, **startups**, and **content creators**. It integrates deeply with RJBuilder, giving you full control over your layout, colors, and content directly from the admin panel — without writing a single line of code.

## ✨ Features

| Feature | Description |
| --- | --- |
| **RJBuilder Integration** | Custom *Glass Header* and *Cinematic Hero* widgets tailored for modern dark designs. |
| **Dynamic Customizer** | Live CSS variables for colors, typography, and layout. Changes reflect instantly on the frontend. |
| **Glassmorphism UI** | Beautiful frosted-glass effects with a sleek dark aesthetic. |
| **Fully Responsive** | Optimized for desktop, tablet, and mobile devices. |
| **Multilingual** | Built-in language switcher with automatic RTL support. |
| **Custom Page Templates** | Dedicated templates for Contact, Landing, and Full-Width pages. |
| **Performance First** | Lightweight, no unnecessary CSS/JS frameworks, optimized for fast loading. |

## 📋 Requirements

- **RJ CMS** 1.0.0 or newer
- **PHP** 8.2 or newer

## 🚀 Installation

1. Clone or download this repository into the RJ CMS themes directory:

   ```bash
   cd rj-content/themes
   git clone https://github.com/rj-nexus/spotlight.git
   ```

2. Log in to the RJ CMS admin panel.
3. Go to **Appearance → Themes**.
4. Find **Spotlight** and click **Activate**.
5. Open the **Customizer** to set your colors, fonts, and layout.

## 🧱 Getting Started with RJBuilder

1. Go to **RJBuilder** in the admin panel.
2. Create a new **Page** or **Template** (Header/Footer).
3. Find the **Spotlight** category in the block list.
4. Drag and drop the **Glass Header** or **Cinematic Hero** widgets.
5. Customize the widget settings (add a background video, change text, etc.) and save.

> [!TIP]
> Use the Customizer for global styles (colors, fonts, layout) and widget settings for per-section content.
